# -notes-manager-android
Application Android de gestion de notes personnelles.
# 📝 Gestionnaire de Notes — Android Java

Application mobile Android développée dans le cadre de l'examen final
du module Introduction au Développement Android (TP Mobile 2025/2026)
à l'École Supérieure Polytechnique (ESP/UCAD).

## Fonctionnalités
- Créer, modifier et consulter des notes personnelles
- Attribuer une couleur à chaque note via une palette intégrée
- Marquer des notes en favoris (double clic)
- Rechercher une note par titre en temps réel
- Filtrer l'affichage sur les favoris uniquement
- Persistance locale des données avec Room (SQLite)

## Stack technique
- **Langage** : Java
- **Persistance** : Room (SQLite)
- **UI** : RecyclerView, CardView, FloatingActionButton
- **Architecture** : MVC — séparation Model / View / Controller
- **Min SDK** : API 21 (Android 5.0)
